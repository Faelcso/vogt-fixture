# How to Reset the Fixture

To rebuild the repository and reset the fixture environment, an operator must follow the steps below:

1. Ensure you have the required dependencies installed.
2. Locate the reset script in the root directory of the project.
3. Run the reset script using the following command:
   ```bash
   ./reset.sh
## Configuration Manife
The reset script relies on the configuration manifest to determine the initial state of the fixture. You can find the manifest file here: [Link to Manifest](./manifest.json)
